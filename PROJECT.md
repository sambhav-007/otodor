# OTODOR Website Project

## Overview

OTODOR is a premium smart security brand offering digital door locks, gate locks, hotel locks, and gate automation solutions.

This is NOT a generic Shopify store.

The objective is to create a premium technology brand experience comparable to Qubo, Apple product launches, and modern consumer electronics websites.

The website should feel innovative, trustworthy, futuristic, and premium.

---

# Primary Goal

Create a website that immediately communicates:

* Premium Security
* Advanced Technology
* Luxury Design
* Trust & Reliability

The user should feel that OTODOR products belong in modern homes, villas, offices, hotels, and premium residential spaces.
